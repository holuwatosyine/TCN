# Kingshill School of Discovery

React and Vite website for Nigeria's first registered coaching academy.

## Local development

```sh
npm install
npm run dev
```

The development server runs on the port shown in the terminal, normally `http://127.0.0.1:8080/`.

## Production build

```sh
npm run build
```

## Routes

- `/` — homepage
- `/about` — academy story and values
- `/training` — programmes and designations
- `/faculty` — faculty directory
- `/resources` — coaching resources
- `/gallery` — community gallery
- `/contact` — contact form and locations
